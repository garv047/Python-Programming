# Strings and Sets

## Overview
This project demonstrates the basic concepts of Strings and Sets in Python. It covers common string operations and set manipulation techniques.

## Features
- String creation and operations
- String slicing and concatenation
- Set creation
- Adding and removing elements
- Set operations (union, intersection, difference)

## Requirements
- Python 3.x

## How to Run

python main.py

## Sample Output

String: Hello World
Length: 11

Set: {1, 2, 3, 4}
Union: {1, 2, 3, 4, 5, 6}

## Conclusion
This project helps in understanding the fundamentals of Strings and Sets in Python.
