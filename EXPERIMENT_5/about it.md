# Lists, Tuples, and Dictionaries

## Overview
This project demonstrates the basic concepts of Lists, Tuples, and Dictionaries in Python. It covers creating, accessing, and manipulating these data structures.

## Features
- List operations
- Tuple creation and access
- Dictionary creation and manipulation
- Adding, updating, and removing elements
- Accessing data using indexing and keys

## Requirements
- Python 3.x

## How to Run

python main.py

## Sample Output

List: [10, 20, 30, 40]

Tuple: (1, 2, 3, 4)

Dictionary:
{'name': 'Garv', 'dob': 04042007 }

## Conclusion
This project helps in understanding the fundamentals of Lists, Tuples, and Dictionaries in Python.
