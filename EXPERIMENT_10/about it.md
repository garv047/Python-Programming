# Data Analysis and Visualization using NumPy

## Overview
This project demonstrates basic data analysis and visualization using NumPy. It covers numerical computations, statistical analysis, and data visualization techniques.

## Features
- Creating NumPy arrays
- Performing mathematical operations
- Calculating mean, median, and standard deviation
- Data analysis using NumPy functions
- Visualizing data with graphs

## Requirements
- Python 3.x
- NumPy
- Matplotlib

## How to Run

python main.py

## Sample Output

Mean: 25.0
Median: 25.0
Standard Deviation: 11.18

## Conclusion
This project helps in understanding basic data analysis and visualization techniques using NumPy.
