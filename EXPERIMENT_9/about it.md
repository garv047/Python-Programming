# Classes and Objects

## Overview
This project demonstrates the basic concepts of Classes and Objects in Python using Object-Oriented Programming (OOP).

## Features
- Creating classes
- Creating objects
- Using constructors
- Defining methods
- Accessing attributes

## Sample Code

class Student:
    def __init__(self, name):
        self.name = name

    def display(self):
        print("Name:", self.name)

student1 = Student("Garv")
student1.display()

## Output

Name: Garv

## Requirements
- Python 3.x

## Conclusion
This project helps in understanding the fundamentals of Classes and Objects in Python.
