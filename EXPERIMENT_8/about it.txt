# Tkinter Project

## Introduction
This project is made using Python and Tkinter library. The main purpose of this project is to create a simple desktop application with a graphical user interface (GUI). Tkinter helps in creating interactive applications using buttons, labels, text boxes, and other widgets.

## Features
- Simple and easy-to-use interface
- Interactive GUI components
- User input handling
- Lightweight application
- Easy to run on any system with Python installed

## Technologies Used
- Python
- Tkinter
